# Network Sending

	1. Some printers may require a USB drive to store sliced files if internal storage is not supported.
	1. Network sending requires the printer and the computer to be under the same local area network (LAN).
	1. The transmission speed is limited by printer's network module. Most printers limit the transimission speed to 8M/s. Large files are not recommended for **Network Sending**. 
	1. Only some printers support Network Sending. Read the 📃full compatibility list here.

After slicing your model, click the "Network Sending" button to open the network sending window. 

![](../../../../../../public/images/docs/en-US/chitu-manager/network-sending-01.png)

Edit the file name and choose the format for the sliced file. Then choose the printer you want to use from the printer list or the "My Printer" list. Click the "**Send**" button at the bottom right corner to start saving and transferring the file.

![](../../../../../../public/images/docs/en-US/chitu-manager/network-sending-02.png)

A temporary file is saved before transfer starts. This file is used during the transfer process and is automatically deleted when you close the CHITUBOX slicer.

![](../../../../../../public/images/docs/en-US/chitu-manager/network-sending-03.png)

Once saved, the file will be transferred to the printer.

![](../../../../../../public/images/docs/en-US/chitu-manager/network-sending-04.png)

When the file transfer is complete, click the "Print" button to start printing.

If you run into any issues during the network sending, we have a handy FAQ section available. Click here to view it and troubleshoot any problems you might encounter.

## Sliced File Transfer

After preparing the sliced file, click the file transfer button in the bottom right corner to proceed with the network transfer.

![](../../../../../../public/images/docs/en-US/chitu-manager/Chitumanager-en-01.png)

Select the sliced file by clicking or dragging.

![](../../../../../../public/images/docs/en-US/chitu-manager/Chitumanager-en-02.png)

Choose the desired printer and then click the send button in the bottom right corner.

![](../../../../../../public/images/docs/en-US/chitu-manager/chitumanager-en-03.png)

The file will be transferred to your printer.

![](../../../../../../public/images/docs/en-US/chitu-manager/chitumanager-en-04.png)

Once the transfer is complete, click the print button in the printer to begin printing your file.

![](../../../../../../public/images/docs/en-US/chitu-manager/Chitumanager-en05.png)

If you run into any issues during the transfe, youcan check our FAQ section for troubleshooting tips. Click here to view it.
