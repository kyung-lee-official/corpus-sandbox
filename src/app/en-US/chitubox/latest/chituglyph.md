# ChituGlyph
ChituGlyph is an AI feature within CHITUBOX that enables users to generate 3D models directly within the software by uploading images. Leveraging advanced image processing and machine learning algorithms, it transforms 2D images into printable 3D models, thereby significantly streamlining the entire process from concept to print.

![](../../../../../public/images/docs/en-US/chitubox/latest/chituglygh/entry_us.png)

### Image Requirements
Supported image formats include PNG, JPG, JPEG, and WebP. The maximum file size must not exceed 6MB, and the minimum resolution requirement is 128 x 128 pixels.

If you do not have an image, you can enter a text prompt to instantly generate one.

### Credits and Consumption Guide

ChituGlyph uses credits for feature billing. The credits required for different operations are as follows:

*   **Image Generation**: 20 credits / task
*   **3D Model Generation**: 100 credits / task

You can check your current credit balance at the top left of the interface. Subscribers receive credit benefits based on their subscription tier.

To **top up** your credits, please click **"Purchase More"** in the software to view full plan and benefit details.

> **Note**: Credit consumption is based on actual task submission. It may be adjusted due to version updates or functional optimizations; please refer to the real-time display in the interface.
