# Data Migration
![](../../../../../public/images/docs/en-US/chitubox/latest/data-migration/dm_us.png)
Cross-software updates may involve data risks. This window will automatically pop up when the system detects that you are updating from legacy software (CHITUBOX Basic V2.0 or CHITUBOX Pro V2.0) to the new CHITUBOX.
Please note that data is not synchronized automatically; you need to click the "Start Migrate" button at the bottom to safely import your printing settings, support parameters, and other data from the legacy software into the new CHITUBOX.

![](../../../../../public/images/docs/en-US/chitubox/latest/data-migration/dmsoftware_us.png)
If you did not initiate the migration from the initial pop-up window,  
 you can still do so later by going to Main Menu > Data Migration to safely import your historical configurations.
